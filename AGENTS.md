# Работа с проектом

- Это основа сервиса Datathon 26. Реальный локальный анализатор пока не подключён.
- Не подменять отсутствие модели или ошибку результатом `no_violation`.
- Соблюдать API кейса: X-API-Key, асинхронные задачи, два итоговых вердикта, 1–3 JPEG.
- Не добавлять внешние AI API и распознавание лиц.
- Не использовать исходные имена файлов, SHA-256 или обучающие таймкоды как признаки.
- Видео, кадры, отчёты с кадрами, веса, секреты и `.runtime/` не коммитятся.
  Родительская папка `datathon` не является частью репозитория.
- Выводы о нормах должны сохранять условия применимости и ограничения наблюдения.
- Интерфейс и API-справка используют локальные ресурсы; внешний CDN не нужен.
- Перед завершением изменений выполнить `.venv/bin/ruff check .`,
  `.venv/bin/ruff format --check .`, `.venv/bin/pytest -q`.
- Описывать реальное состояние: тесты инфраструктуры не доказывают качество ML.
