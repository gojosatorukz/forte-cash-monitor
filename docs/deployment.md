# Репозиторий, работающий сервис и сдача

## Что сдаётся по кейсу

Разделы 8 и 10 «Кейс_ForteBank.docx» требуют:

1. Публичный URL работающего интерфейса.
2. Адрес API и ключ для заголовка `X-API-Key`.
3. Инструкцию запуска/использования.
4. Архитектуру, модели, источники правил, категории и ограничения.

Жюри загружает тестовые записи удалённо через API. Если сервис недоступен или
не вернул результат за пять минут, видео считается необработанным.
Наличие подробного README не заменяет работающий публичный сервис.
Дополнительные поля формы сдачи нужно проверить у организаторов.

## Вариант A: Mac с 16 ГБ на площадке

API и локальная MLX-модель запускаются на ноутбуке. ПК после экспериментов/обучения
не нужен. На время проверки нужны питание, отключённый сон и устойчивый сетевой доступ.
Скорость полного анализа должна быть измерена заранее, включая два запроса одновременно.

## Вариант B: ПК с RTX 5080 в офисе

Сервис работает на офисном ПК, ноутбук используется как клиент через браузер.
ПК не обязан находиться в здании хакатона, но остаётся включённым и достижимым
до завершения проверки. Проверить офисный firewall, роутер, CGNAT и допустимый
входящий HTTPS-доступ. Проверять из внешней сети, например с мобильного интернета.

## Вариант C: хостинг Python / арендованный сервер

Технически Python можно размещать на Render или Railway; существуют и GPU-платформы,
например Runpod. Это облачная инфраструктура, а не физически локальный компьютер команды.

В разделе 7 ТЗ запрещены внешние AI API и требуется исполнение всех моделей внутри
развёрнутого командой сервиса. При этом FAQ содержит более широкую формулировку
о дисквалификации за «облачные решения по API». Поэтому самостоятельное размещение
весов на арендованном GPU и способ передачи тестовых видео через сторонний шлюз
нужно явно уточнить у организаторов. Нельзя автоматически считать этот вариант
разрешённым или равнозначным собственному ноутбуку.

Текст вопроса для организаторов (команда отправляет самостоятельно):

> Разрешён ли сервер, арендованный командой, на котором все скачанные open-source
> модели выполняются самостоятельно, без вызовов внешних AI API? Разрешён ли
> HTTPS-туннель до нашего ноутбука/ПК для доступа жюри к интерфейсу и API?

До ответа базовый план — своё оборудование. Размещение на платном хостинге в этой
версии не выполнено; подписки и расходы не создавались.

## Что уже можно запускать

```bash
python scripts/run.py
```

Это локальный режим 127.0.0.1. `--host 0.0.0.0` открывает прослушивание сетевых
интерфейсов, но само по себе не создаёт публичный URL, HTTPS и маршрутизацию из интернета.
Публичное включение проводится отдельным этапом, после реального анализатора и проверки доступа.

Ссылка на GitHub не является ссылкой на запущенный сервис. GitHub Pages поддерживает
статические файлы; Python-сервер и GPU на нём не запускаются.

Официальные технические источники:

- https://render.com/docs/deploy-fastapi
- https://docs.railway.com/guides/fastapi
- https://docs.runpod.io/pods/overview
- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
