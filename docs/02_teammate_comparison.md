## 4. What to adopt from the teammate

1. **X-24 correction** (stamps + journal, п.80) and the **X-46 cue set** (cup and food container in our version, plus their "gesture + origin of the item" check).
2. **Interval output**: each event as start–end ±1 s plus the label point (for example X-38 24–59 s, X-4 51–72 s, X-30 10–18 s). Useful for evidence clips and for matching labels that sit at different points of one interval (X-4 at 57 s vs X-47 at 68 s).
3. **Hard-negative list for the detector** (their p.10): any bright screen, any second person, an open safe door *during access*, any green bag, mixed note colours, no paper ID, the cashier missing from one frame. Each cue fires only in sequence with context. This matches our checkpoint design and is a good test checklist.
4. **Exception clauses to suppress false positives / keep descriptions honest**: п.19 пп.1 digital ID; п.25 (recount with the collector only if damaged); п.32 (intact packs without a sheet-by-sheet count); п.49–50 (mixed «Сборная» packs allowed).
5. **Two confidence fields in the output**: "fact observed" and "legal link". Their formula is visible fact + applicable duty + confirmed deviation net of exceptions = grounded suspicion. Put this into the RU description template, for example «Наблюдение: … Норма: … Требует проверки: …».
6. **Data hygiene**: original filenames use **Cyrillic «Х»** except X-1 and X-2. The pipeline must normalise names (our frames use Latin X). Keep duplicates X-4/X-47 and X-5/X-48 in the same CV fold.
7. **Legal consequences block** (ТК ст.64–66, 52 п.1 пп.13 + 53 п.7-2, 120/123; КоАП 213 not applicable; УК 189 only if theft is proved). All checked as accurate. Use it in the pitch and FAQ, not in per-event citations.
8. **Questions for the organisers** (same as theirs plus ours): exact types of X-1, X-2 and X-44; contents of the X-15 bag.
