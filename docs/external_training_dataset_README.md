## Запуск

Из этой папки, в своём Python-окружении:

```bash
python -m pip install -r requirements-data.txt
python tools/relocate.py
python tools/action_dataset.py --smoke
```

`relocate.py` обновляет абсолютный путь YOLO после переноса на другую машину. Пути видео в JSONL относительны корню этой папки. FFmpeg берётся из `imageio-ffmpeg`; можно задать `FFMPEG_BINARY`.

Для детектора, если установлен Ultralytics, пример запуска:

```bash
yolo detect train model=yolo26n.pt data=prepared/cashier/data.yaml epochs=30 imgsz=640 batch=8 device=mps
```

Для NVIDIA замените `device=mps` на `device=0`. Имя модели — пример; можно передать свои локальные веса. Синтаксис: https://docs.ultralytics.com/modes/train/ . Обучение модели в рамках подготовки данных не запускалось.

Для чтения видео в PyTorch, если PyTorch установлен:

```python
import sys
sys.path.insert(0, "tools")
from action_dataset import ActionDataset
from torch.utils.data import DataLoader
loader = DataLoader(ActionDataset("train", as_torch=True), batch_size=2, shuffle=True)
batch = next(iter(loader))  # video: B,C,T,H,W; label; weight; sample_id
```

Основная метка — действие выбранного участника. Другие действия могут происходить одновременно; это предварительное обучение по основной метке, а не полная многометочная разметка сцены. `annotation_weight` равен 1 для MEVA и 0.5 для PIP; при обучении его нужно явно учесть в функции потерь. Из точного интервала MEVA берутся 16 кадров; у PIP интервал внутри клипа не восстанавливался, используется весь клип. Значения весов — настройка этой подготовки, а не оценка уверенности авторов корпуса.

## Отбор и разделение

PIP: ручная проверка обстановки по контактным листам; оставлены помещения, двери, столы, ноутбуки, документы и предметы. Дворы, автомобили, улицы, слишком плохая видимость исключены. Часть сцен домашняя, камера подвижная; это перенос действий между доменами. Исходный класс взят из каталога официального архива. Скачаны только целые MP4 с корректным заголовком tar и полным декодированием. Полная контрольная сумма архива 54 GB не проверялась.

MEVA: официальные training-аннотации из зафиксированного commit; видеозаписи r13 без нарисованных рамок. Фрагменты вырезаны по диапазонам кадров при проверенных 30 fps; выход — H264, 15 fps, без звука. Фиксированный crop покрывает геометрию участников и окружение. Проверены фактическая длительность и видимость сцены; исключения перечислены в отчёте.

MEVA train: 5, 7, 9, 11, 12 марта; val: 13 и 15 марта 2018. Все камеры одного дня остаются в одной части. PIP используется только для обучения. Пересечений SHA256, исходных видео и групп между train/val нет. Одни и те же актёры MEVA могут встречаться в разные дни; независимость по людям не заявляется.

Cashier: разбиение блоками по числовому индексу внутри двух семейств имён, по 25 индексов с каждой стороны границ исключено; held-out кадры с расстоянием dHash ≤4 от train исключены. Исходные идентификаторы видеозаписей/людей отсутствуют. Такое разбиение уменьшает утечку соседних кадров, но не доказывает независимость сцен. Итоговую систему нарушений нужно оценивать на отложенных исходных банковских видео.

## Границы применения

Передача предмета, оставление сумки или открытая дверь сами по себе не доказывают нарушение. Не покрыты готовыми положительными метками состояние сейфа/ключа, блокировка экрана, пересчёт и подлинность банкнот, цифровая идентификация, еда/напитки и принадлежность денег разным клиентам. `Cash-Payment` и `Card-Payment` сохранены как исходные объектные классы; они не доказывают правильность банковской операции. Правила последовательности действий и дообучение в банковском ракурсе требуют исходных роликов и целевой разметки.
