КОНТРАКТ DATATHON 26

API сервиса

Это рабочая основа. Пока локальная модель не подключена, загрузка возвращает 503, а не выдуманный результат анализа.

Создать задачу

POST /api/v1/analyze · multipart-поле file · MOV · заголовок X-API-Key.

curl -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "X-API-Key: YOUR_LOCAL_KEY" \
  -F "file=@/path/to/video.mov"

После подключения модели: HTTP 202 и {"job_id":"…"}.

Получить состояние

curl http://127.0.0.1:8000/api/v1/jobs/JOB_ID \
  -H "X-API-Key: YOUR_LOCAL_KEY"

Статусы: processing, done, failed. Только завершённый анализ возвращает verdict и violations.

Готовность

/healthz — сервер запущен. /readyz — готов ли анализатор. HTTP 503 при неподключённой модели ожидаем.

Документация и интерфейс используют только локальные файлы, без внешних шрифтов и CDN.
