DATATHON 26 · КОНТРАКТ ДЛЯ ЖЮРИ

Один API.
От видео до доказательств.

Все пути /api/v1/* требуют заголовок X-API-Key. Значение передаётся жюри отдельно. Ключ не передаётся в URL.

Готовность сервера и модели проверяется отдельно: /readyz. Без подключённой модели создание задачи возвращает 503. Неполная или ошибочная обработка не выдаёт вердикт.

01 · Загрузить видео

POST /api/v1/analyze · multipart-поле file · MOV. Ограничение файла по умолчанию — 64 МиБ. 

curl -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@/path/to/video.mov"

HTTP 202:

{"job_id":"3f2a9c1e-2338-4f74-b886-30f63edec541"}

02 · Получить результат

curl http://127.0.0.1:8000/api/v1/jobs/JOB_ID \
  -H "X-API-Key: YOUR_KEY"

Пока идёт обработка:

{"job_id":"…","status":"processing"}

После завершения:

{
  "job_id": "…",
  "status": "done",
  "verdict": "violation",
  "violations": [{
    "type": "Название наблюдаемого сценария",
    "timecode_sec": 44.2,
    "description": "Факты, условия и нормативное основание РК",
    "evidence_frames": [
      {"timestamp_sec": 44.2, "image_base64": "JPEG_BASE64"}
    ]
  }]
}

Пример показывает структуру, а не результат реального видео. Для no_violation список violations пуст. На событие возвращается 1–3 настоящих JPEG. Время — секунды от начала исходной записи; base64 без префикса data URL. Источник нормы, пункт и ограничения вывода указываются в описании события.

При ошибке — HTTP 200 с status: failed, объектом error (code, message) и без verdict. Бюджет по умолчанию — 270 секунд, включая очередь; лимит ТЗ — 5 минут. Опрос — каждые 1–2 секунды.

Дополнительные методы интерфейса

GET Назначение

Ошибки запроса

401 — ключ; 404 — задача или файл; 408 — время загрузки; 413 — размер; 415 — формат; 422 — параметры; 429 — очередь; 503 — анализатор не готов. Сетевой сбой при загрузке не гарантирует, что задача не была создана: сначала проверьте историю, затем повторяйте загрузку.

Данные и доступ

По умолчанию завершённые проверки и исходные загрузки удаляются через 24 часа. Один ключ даёт доступ ко всей истории сервиса; это командный прототип, без отдельных аккаунтов пользователей. Интерфейс, справка и отчёты используют локальные ресурсы. Вернуться к проверкам →
